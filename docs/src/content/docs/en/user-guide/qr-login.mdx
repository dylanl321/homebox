title: QR Login
---

import { Steps } from '@astrojs/starlight/components'

If you are already signed in on one device (for example a computer), you can sign in on a phone without typing your password.

<Steps>
1. On the signed-in device, open **Profile**.
2. Under **QR Login**, generate a login QR code.
3. Scan the code with your phone's camera (or open the encoded link in a Homebox-compatible app).
4. The phone opens Homebox and signs in automatically. The code expires in two minutes and can only be used once.
</Steps>
